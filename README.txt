GökAI Android Project

Bu proje doğrudan Android Studio ile APK'ya derlenebilir.

Özellikler:
- ChatGPT hesabına/uygulamasına bağlı değildir.
- GökAI adı ve kullanıcı tarafından sağlanan logo.
- "Yaratıcın kim?" -> "Benim yaratıcım Göktuğ Ege Genç."
- Hızlı / Düşün / Çalışma modları.
- Güncel soru algılama ve DuckDuckGo web araması.
- İstenirse 🌐 butonuyla her soruda web araması.
- Web sonuçlarını AI cevabına bağlam olarak verir.
- İnternet üzerinden bağımsız AI servisine istek gönderir.
- Mikrofon ile Türkçe sesli yazma.
- Metin tabanlı dosya seçip soruya dahil etme.
- Sohbet geçmişini telefonda saklama.

APK oluşturma:
1. Android Studio'da bu klasörü açın.
2. Gradle senkronizasyonunun bitmesini bekleyin.
3. Build > Build APK(s).
4. APK app/build/outputs/apk/debug/app-debug.apk altında oluşur.

NOT:
Bu sürüm internetlidir. Kullandığı üçüncü taraf AI/search servisleri zaman içinde değişebilir.
